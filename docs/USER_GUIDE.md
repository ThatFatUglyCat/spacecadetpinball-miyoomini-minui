# User guide

## English

1. Install the `PINBALL.pak` under `Emus/miyoomini/` on a MinUI SD card.
2. Create `Roms/Space Cadet Pinball (PINBALL)/`.
3. Copy **your** `PINBALL.DAT` into that folder (from a legitimate Windows /
   Full Tilt copy). Do not ask the project for game files.
4. Launch the DAT from MinUI. If the file is missing or invalid, the core shows
   an on-screen help message. Logs: `/.userdata/miyoomini/logs/PINBALL.txt`.

Default controls are documented in `docs/INPUT_MAPPING.md`.

## Português

1. Instale o `PINBALL.pak` em `Emus/miyoomini/` no cartão MinUI.
2. Crie `Roms/Space Cadet Pinball (PINBALL)/`.
3. Copie o **seu** `PINBALL.DAT` (cópia legítima) para essa pasta.
4. Abra o DAT no MinUI. Sem arquivo válido, o core mostra uma tela de ajuda.
   Log: `/.userdata/miyoomini/logs/PINBALL.txt`.

Controles padrão: `docs/INPUT_MAPPING.md`.
