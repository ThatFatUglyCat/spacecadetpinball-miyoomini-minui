## Game data

No game data files (`PINBALL.DAT`, `CADET.DAT`, MIDI, WAV, sprites, or
derivatives) are distributed by this project. You must supply your own
legitimately obtained copies at runtime.

## Hardware reference port

Control scheme and hardware behaviour notes were cross-checked against the
OnionOS standalone port
[cacuracaptors/spacecadetpinball-miyoomini](https://github.com/cacuracaptors/spacecadetpinball-miyoomini).
That project is a separate SDL2/OnionOS port; this repository is a libretro core
for MinUI and does not redistribute that port's runtime or launcher.
